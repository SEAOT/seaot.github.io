# Website photo library — SEA OtTeRS & SEAL Lab

Collected September 4, 2026. File names follow `Subject_description_source.ext`.
Files prefixed `NEWS_` are for the News section; `logo_` are badges/logos; everything else is for Projects/Facilities pages.

## Usage notes

- **Canva crops** (`_SPIE-deck`, `_SPDT-poster`, `_ST70-deck`): cropped from your own Canva designs exported at 7680 px / 8981 px. These are the team's own photos, so no external credit is needed, but the originals in your camera roll will be sharper than a slide crop. Good enough for web cards and headers (most are 1,100–4,000 px wide).
- **NARIT website** (`_NARIT-website`): downloaded from narit.or.th technology and observatory pages. Credit **NARIT** when used; you are inside the institute, but the site's photographers are not named on the pages.
- **ESA** (`ARRAKIHS_*`): from the ESA adoption release (June 10, 2026). The two simulated images are **CC BY 4.0** — credit exactly as listed below. The binocular photo is credited *Satlantis / Arrakihs Mission Consortium* with no open license stated, so use it only with that credit and treat it as editorial use.
- **indico** (`_indico`): posters, flyers and group photos from the event pages on indico.narit.or.th (NARIT-hosted events you chaired).
- **Not available:** Facebook (NARIT page) blocks automated access, so nothing was pulled from there. If there are specific Facebook albums (CoLoRS first light, SEA-SPARC prep, ThaiPASS), download those manually and drop them in this folder.
